# Embedded Programming Hub

This repository is now focused on the publishable web version of the project.

## Main Entry Points

- Public landing page: `index.html`
- Interactive dashboard: `web/index.html`

## Site Structure

- `index.html`
  Public homepage for publishing.
- `about.html`
  Short project overview page.
- `contact.html`
  Contact/support page placeholder.
- `css/`
  Shared styling for the root website.
- `js/`
  Shared JavaScript for the root website.
- `images/`
  Root website images, including `logo.png`.
- `web/`
  Interactive simulations, experiments, shared scripts, and menu assets.
- `assets/`
  Shared project assets still used by the interactive web pages.

## Publishing

Publish the repository root as a static website. The public entry page is `index.html`, and the main classroom dashboard is available from there.

## Notes

- Use Chrome or Edge for Web Serial experiments.
- Prefer `https` or `localhost` when Web Serial is involved.
