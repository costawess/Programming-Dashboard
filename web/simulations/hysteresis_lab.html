Comparator logic

One threshold if (signal >= threshold) { output = ON; } else { output = OFF; }
With hysteresis if (signal >= upper) { output = ON; } else if (signal <= lower) { output = OFF; }

2. One threshold only

The noisy signal crosses the same threshold repeatedly, so the digital output flips on and off around the boundary.

3. Two thresholds with hysteresis

The output only turns on above the upper threshold and only turns off below the lower threshold, so the middle band keeps the previous state.
